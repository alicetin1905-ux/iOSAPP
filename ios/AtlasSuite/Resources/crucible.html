Estimated liquidation levels assumptions
These levels are modelled, not reported. No exchange publishes where open positions would be liquidated. This builds a volume profile from the last few days, splits it across the leverage mix below, computes each cohort's exact liquidation price, then discards any cohort whose level price already traded through. Change the assumptions and the picture changes — treat it as a map of where stops likely cluster, not as fact. The two nearest clusters read out at the top of the page.

Raw socket messages (for debugging a feed)
—
Bybit, Binance, OKX and Bitget publish liquidation streams; this reads all four directly from the browser, one connection each carrying all three symbols. Exchanges report bankruptcy price, not fill price, so notional is approximate. Every symbol keeps its own baseline, cascade log and model assumptions. The intensity baseline is stored in this browser and needs 30 minutes before it will score anything; it sharpens over about a day.
